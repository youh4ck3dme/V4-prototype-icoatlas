# V4 Project Rules & Data Protection

To prevent regressions in future sessions or when editing the codebase, the following requirements are strictly enforced:

## 1. Corporate Identifiers Protection (DIČ/NIP/Adószám)
- **Do not break or remove the `dic` property** from the company detail payload returned by the unified backend search endpoint (`search_v4.py`).
- **Slovakia (SK):** Must parse `tin` (DIČ) from Autoform API or strip the `SK` prefix from the `vatin` string.
- **Czechia (CZ):** Must preserve the raw response from ARES and retrieve `dic` from it.
- **Poland (PL):** Must extract NIP using regex and checksum validation from the Playwright scraper page.
- **Hungary (HU):** Must extract Adószám format (`XXXXXXXX-Y-ZZ`) from the page text.
- **Frontend Mapping:** The `HomePageNew.jsx` search data mapping must map `dic: companyData.dic` in the node fallback block.

## 2. Test Integrity
- Always run the backend tests (`./run_tests.sh`) when modifying any registry scraper, endpoint, or frontend mapping to ensure no data models are broken.
- Ensure the newly added `test_v4_dic_fields.py` passes successfully.
